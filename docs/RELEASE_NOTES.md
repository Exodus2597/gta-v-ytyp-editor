Windows editor for GTA V prop archetypes.

- Open native YTYP or CodeWalker XML, create new files, and add/edit/delete props.
- Edit textures, dictionary references, flags, special attributes, and bounds in one form.
- Import Legacy YDR or Drawable XML; export prop JSON and CodeWalker XML.
- Build native YTYP with round-trip verification, backups, and undo/redo.
- Portable single executable; no .NET installation required.
- MIT licence for the editor's source; dependency notices included.
